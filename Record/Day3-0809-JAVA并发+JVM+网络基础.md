## 继承、多态、接口
### 继承
>继承表示子类可以使用父类的所有属性和方法，还可以自己重写父类方法或者实现其他方法等。
>主要的作用是减少重复代码，把多个子类共有的内容抽取到父类中。
实现
```java
public class Dog extends Animal {
}
```

### 多态
>多态表示父类引用指向了子类，调用重写方法时执行的子类的方法
例子
```
Animal animal = new Dog();
animal.eat();
```

### 接口
>定义能力或规范，实现类必须按约定实现方法。
>在接口的定义的方法其实现类中必须要实现

## JAVA并发基础

### 进程
>进程是一个正在运行的程序实例，比如说正在运行的Java程序，打开浏览器会有相关进程，进程管理资源，是资源分配的基本单位

### 线程
>线程是CPU调度执行的基本单位，一个进程可以包含多个线程，同一个进程中的多个线程会共享该进程的内存资源，每个线程还有自己的执行路径

```text
对于两个线程的运行，他们不是一个线程结束在执行另一个线程而是交替执行，因为线程调度是由CPU/操作系统决定，输出顺序不保证固定，不完全由代码顺序决定
对于创建的线程start()是启动线程，线程内部的run()方法是真正执行的任务内容。
同一个线程只能start一次
```
```
对于多个线程共享资源修改的问题，如果没有相应的异步操作，如果同时修改一个共享资源有可能会出现资源覆盖问题导致修改的内容并不是正确的
因为对于一个共享变量线程修改的操作是先读取共享变量的当前值，然后在当前值得基础上进行修改，最后把新值写回变量中
如果两个线程同时读到同一个旧值，例如都读到 `100`，然后都计算成 `101`，最后都写回 `101`，那么理论上应该加两次，实际只体现了一次。
```
对于主线程需要等待子线程结束后输出一些共享变量的情况可以用join方法来等待子线程结束

#### final关键字
在 `main` 方法中定义局部内部类时，如果内部类访问外部方法的局部变量，这个变量必须是 `final` 或 effectively final。
所以：

```java
int count = 0;
```

如果在线程内部执行：

```java
count++;
```

通常不允许，因为这是在修改外部方法的局部变量。
需要将该变量修改为final int[] count = {0};
这样final字段表示count这个数组的引用不能指向别的数组，数组内部的元素还可以修改

也可以将count 变量用static修饰写在一个类变量中，就可以被引用了

## JVM入门
>JVM是Java虚拟机，用来运行Java字节码
```
Java 源代码先编译成平台无关的 .class 字节码。
不同操作系统安装对应版本的 JVM。
JVM 负责把字节码解释或编译成本机能执行的机器指令。
```

Java运行的流程：

```text
.java 源文件
-> javac 编译
-> .class 字节码文件
-> JVM 加载并运行字节码
```

### 对于JVM内部存储

```text
每次方法调用，都会在线程自己的栈中创建一个栈帧。
方法里的局部变量、部分中间计算结果、方法返回信息等，会放在这个栈帧里。
方法执行结束，对应栈帧出栈。
```

```text
new 出来的 User 对象在堆中。
局部变量 user 这个引用在栈帧中。
user 保存的是堆中对象的引用地址。
```

对于一个对象以后再也没有任何的引用可以访问到这种情况，它就会变成垃圾回收对象，不会立即消失，但之后可能会被GC回收

### 栈、堆、GC
```text
栈：线程私有，主要保存方法调用栈帧、局部变量等。
堆：线程共享，主要保存 new 出来的对象。
GC：垃圾回收，主要清理堆中不可达对象，释放内存。
```
```java
public static void changeInt(int x) {
    x = 99;
}

public static void changeUser(User user) {
    user.setName("changed");
}
```

```text
Java 方法传参都是值传递。
基本类型传的是值的副本。
对象类型传的是引用的副本。
```

对于值副本的传递，对于上述的函数调用修改的变量只是x的值并非传进来的变量
对于引用传递，就会指向同一个对象，所以说changeUser函数就会直接修改传递进来的user对象内的值


## 网络基础
各方面的作用
- Postman / 浏览器：客户端
- Spring Boot：服务端
- HTTP：客户端和服务端说话的格式
- TCP：底层负责可靠地把数据送过去

基础概念
- 网络通信：
一个程序把数据发给另一个程序，另一个程序处理后再返回结果。

- TCP：
可靠、有连接、保证顺序，适合登录、支付、提交表单、访问网页、调用接口。

- UDP：
不保证可靠，不需要先建立连接，速度快，适合直播、语音、游戏等实时场景。

- HTTP：
客户端和服务端之间的请求响应规则。Spring Boot 接口就是处理 HTTP 请求并返回 HTTP 响应。

### HTTP请求对应Spring Boot的注解URL 路径变量 -> @PathVariable
- Query 参数 -> @RequestParam
- 请求头 -> @RequestHeader
- JSON 请求体 -> @RequestBody
- 请求方法 + URL -> @GetMapping / @PostMapping / @PutMapping / @DeleteMapping
